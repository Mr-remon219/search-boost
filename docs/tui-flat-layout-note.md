# TUI 平铺 / 文件夹布局设计笔记

> 本文保留 beta.6 获批准的布局设计与验收依据，不是 beta.7 当前菜单。beta.7 删除自更新并将安装/刷新/卸载合并到“管理 Agent 接入”；当前行为见 [tui.md](tui.md) 和 [管理接入 note](agent-integration-management-note.md)。

- **状态**：用户已确认设计，beta.6 实现已集成；本笔记保留设计依据，实际行为与验证边界见 [tui.md](./tui.md) 和 beta.6 发布记录。
- **关联问题**：BUG-004，当前文件夹式导航增加了直接访问功能的层级。
- **现有实现说明**：见 [tui.md](./tui.md)。该文档描述实现后的当前行为，本笔记保留获批准的目标与验收要求。
- **范围**：默认平铺，保留文件夹模式；两种布局共享功能和执行逻辑，只改变入口排列。包括下文明确列出的引擎配置导航与更新确认优化。

## 1. 默认平铺主菜单与排序

```text
search-boost v0.2.4-beta.x
请选择操作

❯ 首次配置向导              从零配置并安装接入
  安装 / 刷新 Agent 接入     为指定宿主安装或刷新配置
  更新 SearchBoost          更新软件包与所有已安装接入
  查看当前状态              查看接入、引擎与凭据状态

  搜索引擎配置              API Keys / Base URLs / 引擎启停
  默认搜索层                当前：free
  工具开关                  启用或停用工具入口
  X 凭据                    Grok 登录 / XAI API Key
  Jev 配置                  实验性 · adaptive_search

  原生搜索替换              替换或保留宿主内置搜索
  输出 MCP 配置片段         用于手动配置
  卸载 Agent 接入           移除指定宿主的接入

  TUI 设置                  布局 / 显示语言
  退出

↑↓ 选择 · Enter 进入 · Esc 退出
```

空行只作视觉分隔，不是可进入的分类，也不占选择项；小终端使用滚动列表，不要求一次展示全部。状态提示使用实际当前值，上图仅为示意。

排序原则：

1. 首次配置、安装、更新、状态在最上方，兼顾新用户开始使用与老用户维护。
2. 引擎、搜索层、工具、X、Jev 集中排列，实验性配置靠后。
3. 原生搜索、MCP 片段、卸载属于特定需求或低频操作；卸载远离安装。
4. TUI 设置与退出固定在底部。
5. 排序固定，不随使用次数或安装状态自动重排；同一会话完成操作后返回原来的选中位置。

平铺指一级入口平铺，不取消必要的对象选择、参数设置或安全确认。能直接选择参数的操作不另加“开始配置”层。

## 2. 入口内部流程与二级内容

### 首次配置向导

连续向导，不做成另一组分类菜单：

```text
搜索引擎凭据 → 默认搜索层 → X 凭据（可跳过）
→ 选择 Agent → 宿主相关选项 → 确认并安装
```

Jev 是可选实验性服务，不强迫新用户在首次配置中设置。

### 安装 / 刷新 Agent 接入

直接进入宿主多选，展示检测与接入状态：Cursor IDE、Cursor CLI、Codex、Claude Code、Grok、Antigravity、Pi、DSH。

选择后只询问相关参数：

- DSH：CLI / Desktop / All 与目标 profile，按宿主适用条件显示。
- Grok：用户级 / 项目级作用域。
- 支持的宿主：自动授权、原生搜索替换。
- Antigravity：是否写入当前工作区。

不重新询问 API Keys、搜索层与 X 凭据。

### 更新 SearchBoost

进入后先展示当前版本、更新范围和保留内容，再提供“开始更新 / 返回”。选中主菜单入口不立即执行修改。

- 更新范围：SearchBoost 软件包与所有已安装 Agent 接入。
- 保留内容：用户配置、凭据、权限选择。
- 执行结果按目标展示成功、失败、受阻原因。
- 保留现有更新安全行为：模块替换后不继续运行旧 TUI；不因布局变更改动频道选择、版本规则或信任边界。

### 查看当前状态

直接显示只读状态，不另套分类：软件包版本、Agent 接入、默认搜索层、引擎启用与凭据状态、工具开关、X / Jev 状态，然后返回主菜单。

凭据仅显示是否配置、来源和脱敏信息。

### 搜索引擎配置

改为任选引擎，不再要求每次依次走完所有引擎：

```text
搜索引擎配置
  Tavily             凭据 / 启用状态
  Brave              凭据 / 启用状态
  Exa                凭据 / 启用状态
  AnySearch          匿名 / Key 状态
  其他凭据槽位       仅保存，适配器待实现
  引擎启用 / 停用
  返回
```

选择已支持引擎后：

```text
设置 / 更换 API Key
设置 / 更换 Base URL
恢复默认 Base URL
移除文件中的 Key
返回搜索引擎配置
```

未实现的引擎明确标记“仅保存凭据”，不呈现为已参与搜索。保留自定义网关的查询与凭据发送提示、环境变量优先级和并发写入保护。

### 默认搜索层

直接选择 `free` 或 `api`，显示当前值；继续对应现有默认层设置。单次工具调用的 `engine_pool` 是另一项概念，不与默认层混淆。

### 工具开关

直接展示实际支持工具的多选、当前状态与依赖说明，然后“预览变更 → 确认保存”。

包括 `fused_search`、`fetch_page`、`x_search`、`adaptive_search`、并行研究入口、`search_stats`、`search_layer`；按宿主支持情况标注，不把不同宿主的入口名称强行统一成可调用工具名。

- Jev 未配置时，`adaptive_search` 明确标记不可用。
- 说明关闭 `x_search` 入口不等于关闭 fused 的社区检索。
- 保留工具依赖检查与运行中调用的既有处理，不因布局改变权限范围。

### X 凭据

先展示当前来源与脱敏状态，然后：

```text
从 Grok 登录导入
设置 / 更换 XAI API Key
移除本地凭据副本
返回主菜单
```

没有 Grok 会话时显示原因。移除本地副本不声称清除了环境变量或 Grok 原始登录。

### Jev 配置

标注实验性，展示当前地址与脱敏凭据状态，然后：

```text
设置 / 更换 Base URL 与 API Key
移除文件中的配置
返回主菜单
```

说明问题、搜索意图和必要片段会发送至配置的服务。

### 原生搜索替换

当前状态 → 选择支持配置开关的 Agent → 替换 / 保留 → 确认。仅提示优先的宿主不冒充支持配置级禁用。

### 输出 MCP 配置片段

选择 Agent → 自动授权选项 → 原生搜索选项 → 输出，不写入配置。

### 卸载 Agent 接入

选择 Agent / DSH 目标 → 展示移除范围 → 明确确认，默认取消。不因名称看起来像测试 profile 自动删除或跳过目标。

## 3. TUI 设置与布局持久化

```text
TUI 设置
  菜单布局          平铺
  显示语言          简体中文
  返回主菜单
```

布局在语言之前。布局选择：

```text
菜单布局
  ● 平铺（默认）    所有功能直接列在主菜单
  ○ 文件夹          先选分类，再选功能
  返回 TUI 设置
```

规则：

- 没有保存过布局偏好时默认平铺，包括只有语言设置的旧配置。
- 用户明确选择后保存，下次启动沿用；保留其他已保存设置。
- 切换立即生效，回到新布局主菜单。
- 不修改搜索配置、凭据、宿主接入或非交互 CLI 行为。
- 两种布局共享操作逻辑与功能定义，避免功能遗漏或操作行为分叉。
- dry-run 可预览布局，不持久化；取消未提交选择不保存。
- 设置读取损坏时提示错误，临时回退默认布局，不自动覆盖坏文件；保存失败不得伪报成功。
- 具体配置字段和实现细节在实施时确定，沿用现有 TUI 设置存储与锁机制。

## 4. 文件夹模式

保留现有分类结构，使用相同功能与操作流程：

```text
安装与接入
  首次配置向导
  安装 / 刷新 Agent 接入
  原生搜索替换
  输出 MCP 配置片段
  卸载 Agent 接入

搜索与工具
  默认搜索层
  工具开关

服务与凭据
  搜索引擎配置
  X 凭据
  Jev 配置

更新与状态
  更新 SearchBoost
  查看当前状态

TUI 设置
  菜单布局
  显示语言

退出
```

## 5. 导航与验收方向

- 平铺模式：操作完成后返回主菜单并保留选中项；内部返回按层级导航。
- 文件夹模式：操作完成后留在所属分类；分类返回主菜单。
- 向导 Esc 取消当前操作，回到所属入口层级；主菜单 Esc 退出，Ctrl+C 退出整个 TUI。
- 取消不承诺回滚此前已完成并保存的独立步骤，也不撤销已经执行的安装或更新。
- 全部现有功能在两种模式下都可到达；默认平铺、旧语言配置迁移、显式布局偏好、即时切换、跨进程保存均须覆盖。
- 覆盖菜单顺序、返回与取消、更新确认与模块替换退出、小终端滚动、双语提示、设置并发/损坏与 dry-run。
- 引擎配置任选入口须覆盖返回、保留未改字段及凭据脱敏；危险操作不得因扁平导航减少确认。
- 测试使用隔离 HOME 和工作区，不读写真实用户状态。

本阶段只记录已确认设计，未修改 TUI 实现、用户设置或发布版本。
