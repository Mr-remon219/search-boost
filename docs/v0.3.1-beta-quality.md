## 每轮都要重跑的核心

这些是计划中的必测项。某一轮只有在自己的测试记录里写了结果，才算这一轮测过。P0/P1 要在该轮记录里清零，不能沿用上一轮的结论。

- 单引擎失败或空结果时，不暗中改叫别的引擎或别的协议。
- 缺 Key：零次出站，并且是错误，不是空结果成功。
- HTTP 200 且结果为空：成功，`isError` 为 false。
- 取消之后不再发出新请求。
- 重试：未来 HTTP-date、整数秒、非法字符串、小数 `1.5`。`1.5` 是 1.5 秒，不是日期。
- 来源字段：缺 `summary` 就省略，`null` 保持 `null`，空字符串保持空字符串。
- 同一 URL 合并后，`provenance` 仍能看出每一家来源。

live 调用和费用保持 NOT RUN。没有 live key，不写认证通过。

## 产品对 beta.2 的界面门槛

这些来自对 `cc49eee` 的隔离 PTY 复核，不是实测通过结论。beta.2 要在自己的渲染里满足它们。已有的静态栅格 PNG 含盲文和 256 色近似，不能当作配色通过证据。本轮留文本回放，并在测试里检查真彩序列没有出现在 `NO_COLOR` 输出中。

- G2.1：80×24 和中文 60×20 的全屏总览首屏直接有默认引擎名单，以及收费或免 Key 完整配置。长配置路径后置。轻量首页在默认搜索项上显示名单和费用，不只在 Enter 后的长日志里。
- G2.3：默认搜索详情第一屏能读完名单、费用和有效源。协议可以翻页，80×24 不超过 1 次 PgDn，60×20 不超过 2 次。中文费用不截断。轻量日志不把 `POST` 切成 `P/OST`，也不把 `official` 切成 `fficial`。
- G2.4：低于 112 列时，脚注里的 Enter 先进入自动选择详情，不直接跳到引擎开关。管理开关只在详情可见时执行。60×20 和 80×24 的确认同时看见取消、确认和未确认不保存，默认取消。
- G2.2：焦点、选中和停用保留符号或文字。G2.5：取消不写配置，并回到原来的条目。120×40 三栏不退步。

产品量过的步数只到目标和确认，不是完整任务：默认源全屏 1 键、轻量 4 次 Down；选一家到确认全屏 13、轻量 16；停用收费源全屏 12。这只作参考，不写成加速。

## beta.2 本轮要亲跑的界面

计划要求这一轮自己跑，不引用 beta.1 的界面结论：

- 键盘：`1`–`8`、方向键、`j`/`k`、Tab 焦点、Enter、Esc、帮助。
- 中文 54 列窄屏，显示宽度不溢出，第一屏有协议。
- 48 列只显示加宽提示，并且不接受隐藏按键。
- `NO_COLOR`、`--no-color`、`TERM=dumb` 不输出真彩。
- 非 TTY 的 `tui` 失败并指向 `--preview`。
- 确认框默认是取消，回车不写配置。
- 确认期间配置被另一次写入时，本次不覆盖，并说明冲突。
- 引擎页能区分已启用和未配置；缺 Key 诊断写明 `engine_pool` 没有运行。

脚本是 `scripts/test-v031-beta2-ui.mjs`。可读渲染在 `docs/v0.3.1-beta2-ui-before.txt` 和该脚本写出的 `docs/v0.3.1-beta2-ui-after.txt`。

## 通过规则

1. 按 `3` 后，协议在第一屏。
2. 键盘能走完上表，确认框默认仍是取消。本轮不新增开关。
3. `summary` 缺省省略、`null` 保持 `null`、空字符串保持空字符串。
4. 点名的引擎不可用时，`enginesUsed` 为空，且不调用免 Key 池。
5. 缺 Key 文案有句号，并写出 `--show` 和 `--set`。
6. 48 列不溢出，只提示至少 54 列。54 列中文第一屏含协议。无色渲染不含真彩。非 TTY 不带 `--preview` 时失败。

每一项只有通过或失败。不另给 1–5 分。

## beta.1 基线上已知的四项

在 `cc49eee` 上，下面四项不符合上表，所以进入 beta.2：

- 缺 Key 时 `enginePool` 可以是 `free`。
- note 从开头截到 120，结尾丢失。
- 协议句在中英长文之后。
- `Retry-After: 1.5` 被 `Date.parse` 当成 2001-01-05。

## beta.3 计划（未实现，未实测，未打 tag）

用同一组冻结样本，先比正确性、不必要的调用和错误。性能若要比较，每一边至少 5 次，A/B 交替，环境、运行时和负载相同，报告中位数、范围、错误和有效工作量。先做预实验得到噪声界，再登记判据。差异小于波动就记 inconclusive。没有 limiter 或 profile 时不声称加速。合成的 wall time 不是网络效率。
