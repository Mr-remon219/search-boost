# 0.3.1-beta.1 路由决策表

这是实现契约，不是实测性能报告。调用次数是代码里的计划次数，不含 DeepSeek 的 HTTP 重试。没有延迟、QPS 或费用节省数字。

| 输入 | 实际调用 | 失败或空结果 | 终止 |
| --- | --- | --- | --- |
| 省略 `engine_pool` 和 `engines`，至少一把 API Key 已启用 | 只调用这些已启用 API | 不改走免费池或其他未启用 API | 各引擎自己的结果或错误 |
| 同上，但没有任何已启用 API | 可用的免 Key 引擎（bing、ddg、exa-free、可用的 anysearch） | 不调用付费 API | 同上 |
| 当次 `engine_pool=free/api/hybrid` | 该池里当前可用的引擎 | 不换池 | 同上 |
| 当次 `engines: ["id"]` 或只启用一家 | 只这一家 | 不追加其他引擎，不换协议 | 成功、成功零条或该引擎失败 |
| 缺 Key、停用、或引擎不可用 | 零次出站 | 警告说明未调用。只点名一家 API 且未传 `engine_pool` 时，结果里的 `enginePool` 是这家引擎所属的池（DeepSeek 为 `api`），并写明该池没有运行。这不是免 Key 池已经搜索过。`outcome` 为 `unavailable`。 | 不改叫另一家来补 |
| 同一条 query 在 `queries` 里再写一遍，且引擎是 DeepSeek | 只派发一次 | 不去掉不同的 query | 不因为去重改打别的引擎 |
| DeepSeek query 不是 1–128 个 Unicode 码点，或 count 不在 1–50 | 零次出站 | `invalid_request` | 不截断 query |
| DeepSeek HTTP 200 且 `results: []` | 这一次 Search 请求 | 成功零条 | 不 Fetch，不改走 messages |
| DeepSeek HTTP 400/401/402/403/404/413 | 一次 | `http_<status>`，不回显正文 | 不重试，不换引擎 |
| DeepSeek HTTP 408/429/5xx | 最多 1+2 次 HTTP | 预算用尽后失败 | `Retry-After` 按当前时钟解释。纯数字（含一位小数）是秒，不是日期。`1.5` 是 1500ms，超过 1 秒预算就停止，不会被 `Date.parse` 当成 2001-01-05。整数秒大于 1 不再试。HTTP-date 若在未来且等待超过 1 秒则停止，不改用 20/40ms。已过去的日期立即再试，仍受次数预算。无法解析则停止。取消后不再请求。`engineStats.attempts` 仍是计划调度次数，不是 HTTP 次数 |
| 调用方取消 | 不再开始下一次重试 | `cancelled` | 不换引擎 |
| 保存 Key，已有 `enabledEngines` | 白名单不变 | 未列入的引擎不会因为保存而加入默认搜索 | 不联网 |
| 保存 Key，没有白名单 | 不写入白名单；新 Key 按 0.3.0 进入「已配置即启用」 | 默认集合因此变大 | 不联网，不调用第二条协议 |

`routeExplanation` 复述上表的实际集合。它不改集合。

DeepSeek 不参与其他引擎的 OR 拆分。传给它的 query 与调用方字符串一致，`site:` 和 `OR` 原样保留。复杂度只限制额外 `queries` 的条数，不截断单条 query。
