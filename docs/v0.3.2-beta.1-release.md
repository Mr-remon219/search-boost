# SearchBoost 0.3.2-beta.1

版本字符串是 `0.3.2-beta.1`。这是已发 `0.3.1` 上的贡献者补记，不是新引擎，也不是稳定版。本步不打 tag，不发 GitHub Release，也不 `npm publish`。不要执行 `npm install -g search-boost@0.3.2-beta.1`。不要把 `0.3.1` 或 `0.3.1-beta.5` 的 tarball 改名当作这个包。

基线是已发 `v0.3.1`：提交 `bd9893f08eddd1ea96bfaa5b10450032e1fa5375`，tree `93aceac7f0385a1882d255f8a7844fb916ce5be2`。引擎行为以这一版为准。Firecrawl 与 Keenable 已在 `0.3.0` 纳入，并随 `v0.3.1` 发布。本 beta 不改适配器、路由、密钥或请求体。

## 贡献者

树内落点是双 README：

- [English](../README.md#contributors)：`[hardworkDAD](https://github.com/hardworkDAD) — Firecrawl and Keenable keyed engine adapters (PR #40), included since 0.3.0.`
- [中文](../README_zh.md#贡献者)：`[hardworkDAD](https://github.com/hardworkDAD) — Firecrawl 与 Keenable 带钥匙引擎适配器（[PR #40](https://github.com/Mr-remon219/search-boost/pull/40)），自 0.3.0 起纳入。`

代码署名仍在历史提交 `3bbef576017ae3e0f0a83c3986ee4c5f52f8eace`。本说明的提交作者是维护者，不另加文档 Co-author。

已发的 [0.3.0 说明](./v0.3.0-release.md) 与 [0.3.1 说明](./v0.3.1-release.md) 正文不改。

## 安装

安装交付的 tarball，不要从 registry 安装：

```bash
npm install -g /absolute/path/to/search-boost-0.3.2-beta.1.tgz
search-boost --version   # 必须打印 0.3.2-beta.1
```

备份、还原和回滚步骤仍以 [0.3.1 说明](./v0.3.1-release.md) 为准。回滚目标是已发 `v0.3.1`（提交 `bd9893f08eddd1ea96bfaa5b10450032e1fa5375`），不是 registry 上的 `0.3.1` 或 `0.3.0`。

## 本轮没有做的

没有对齐默认搜索措辞。没有额度查询，没有权重校准，不传 `scrapeOptions`，不加 recency / nativeDomains 映射。没有新造 `CONTRIBUTORS` 或 `NOTICE`，没有改 `package.json` 的 contributors，没有改 `LICENSE` 版权行。

没有付费 live 调用，没有使用真实凭据，也没有新的桌面终审。
