# SearchBoost 0.3.2

版本字符串是 `0.3.2`。这是 `0.3.2-beta.1` 贡献者补记的正式候选，不是新功能，也不是再一轮 beta。产品行为以已发 `v0.3.1` 为基线。本步不打 tag，不发 GitHub Release，也不 `npm publish`。不要执行 `npm install -g search-boost@0.3.2`。不要把 `0.3.2-beta.1`、`0.3.1` 或更早的 tarball 改名当作这个包。

已审 beta.1 是 `77cca88517100f2fd2207b4c811651accf2e6767`，tree `71adfcfa17b11101f2bd6e712457ab23edb2f719`。它的包保留：`search-boost-0.3.2-beta.1-77cca88.tgz`，759522 字节，310 个成员，sha256 `e34b61d4c255fa83ded7c49fd064bccda625bf7d4faa45245db0f420a9b6a033`。行为基线仍是已发 `v0.3.1`：`bd9893f08eddd1ea96bfaa5b10450032e1fa5375`，tree `93aceac7f0385a1882d255f8a7844fb916ce5be2`。

## 安装

安装交付的 tarball，不要从 registry 安装：

```bash
npm install -g /absolute/path/to/search-boost-0.3.2.tgz
search-boost --version   # 必须打印 0.3.2
```

备份、还原和回滚步骤仍以 [0.3.1 说明](./v0.3.1-release.md) 为准。回滚目标是已发 `v0.3.1`（提交 `bd9893f08eddd1ea96bfaa5b10450032e1fa5375`），不是 registry 上的 `0.3.2`、`0.3.1` 或 `0.3.0`。

## 后续才承认的缺口

下面这些是已经声明的产品边界。本轮不实现，也不缩小：

- 排序权重仍是未经校准的 1.0，不是实测质量排名。
- 没有额度查询。控制台对这两家显示不支持查询。
- Firecrawl 不传 `scrapeOptions`。
- 没有 recency / nativeDomains 的上游映射。

没有付费 live 调用，没有使用真实凭据，也没有新的桌面终审。这篇说明不是正式放行。
