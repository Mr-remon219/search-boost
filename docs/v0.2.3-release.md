# v0.2.3 — Custom API bases, Jev retrieval and shared tool switches

Node.js requirement remains `>=22.13`. This release integrates PRs [#12](https://github.com/Mr-remon219/search-boost/pull/12), [#16](https://github.com/Mr-remon219/search-boost/pull/16), [#14](https://github.com/Mr-remon219/search-boost/pull/14), and [#15](https://github.com/Mr-remon219/search-boost/pull/15), in that order.

## 新功能与修复

- **自定义 Base URL**：Tavily、Exa、Brave、AnySearch 支持可信 API 网关，保留路径前缀与原有认证方式。TUI 提供编辑、端点预览和恢复默认；CLI 提供 `--base-url engine=URL` / `--reset-base-url engine`。地址变更隔离缓存，AnySearch free 池保持匿名。
- **Jev 检索 V3**：支持 `intent`、问题绑定关键词与逐关键词继续判断，返回按阅读价值排序的原文摘录和匹配来源。每轮最多接纳 500 个候选 URL，实际规模受预算与服务结果限制。修复关键词匹配重试耗尽后仍继续搜索的问题；缺失的必要判断仍不会被当作成功。
- **共享工具开关**：TUI 的 Tool switches 保存到 `tools.json`，支持预览、取消和全部关闭。MCP/Pi 工具列表约 300ms 刷新；DSH 保留注册但拒绝关闭工具的新调用，原生 search/fetch provider 同样受控。已经开始的调用正常完成。
- **DSH 兼容性与安装**：修复 Schema 注册失败，支持 Jev 的平铺/嵌套关键词数组，并使用原始 Schema 校验输入输出。npm/npx 安装固定当前包版本，补齐缺失启动器并验证安装结果。
- **跨平台修复**：修复 Antigravity 符号链接 HOME 检测及升级测试的路径身份判断。CI 覆盖 Linux、Windows、macOS。

## 升级与兼容性说明

```sh
npm install -g search-boost@0.2.3
search-boost upgrade --sync-only -y
```

升级后重启或重载已运行的 MCP/Pi/DSH 适配器；忽略 MCP 工具列表变更通知的客户端可能需要重新连接。用户密钥、已有开关、引擎路由与权限配置保留。自定义网关会接收搜索请求及相应 API 密钥，只应配置可信服务。

`adaptive_search` 保留 `questions`、`tasks` 与 cursor 分页输入。V3 的语义变化需要调用方留意：

- `schemaVersion: 3`；`retrievalSufficient` 表示关键词检索满足判断，不表示答案完整或事实已核实。
- 旧 `coverageComplete` 字段保留，但 V3 中始终为 `false`，不要再把它当作继续检索的唯一条件。
- 查看 `keywordProgress`、`pendingAssessments`、`warnings`；`exhausted` 不是成功，也不是不存在的证明。
- 未配置 Jev 时，宿主工具入口锁定；显式关闭不会被后续凭据变更覆盖。
- 下一页只传 `cursor` 和可选 `page_size`。cursor 是进程内临时状态，重启后失效；分页结束不代表穷尽搜索。

## 验证范围

发布检查包括 `npm run prepublishOnly` 和 `npm run test:dsh-package`，覆盖配置、安装/升级、网络策略、Jev、TUI、三个宿主适配器及 npm/npx 打包安装。整合验证还实际操作了终端 TUI、Pi SDK 热刷新、MCP stdio 动态列表及 DSH 注册器的六工具与 TypeScript/Python Schema 编译。

这些测试不等于对所有真实搜索引擎、Jev 服务或代理环境的在线质量保证，也没有使用用户真实搜索凭据进行质量校准。合并源码、发布 npm 和创建 GitHub Release 是独立步骤；发布状态以 npm registry 和 GitHub Release 为准。

## English summary

Custom API base URLs and endpoint previews are available for Tavily, Exa, Brave and AnySearch. Intent-guided Jev retrieval adds bound keywords, reading-value ranking and explicit continuation states. Shared switches gate MCP, Pi and DSH tools, with live MCP/Pi list updates and a Jev credential lock. DSH schema translation, npm/npx installation and cross-platform path handling are repaired.

**Migration:** V3 keeps `coverageComplete` only as an always-false compatibility field. Inspect `retrievalSufficient`, keyword progress and warnings instead; none establish answer correctness or completeness. Reload existing adapters after upgrading. Live upstream quality and authenticated chat sessions on every platform are outside the automated release checks.
