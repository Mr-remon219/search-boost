# 事实级 Jev 控制器：实现与验证记录

状态：**当前工作树已实现，未提交/发布；模型质量与系数仍 provisional。**
设计见 [jev-evidence-design.md](jev-evidence-design.md)，公共契约见 [jev-adaptive-search.md](jev-adaptive-search.md)。

## 实现范围

- 接入归档V2中的全局500候选、无额外引擎数量帽、批审、比例恢复、分页和预算/截止修复。
- 用 `S=.25A+.90F+.10R` 替代全局文档次序递减；同事实额外独立来源按1/2、1/4、1/8递减。
- 事实来自固定验收单元；可显式提供target.facts，未提供时仅按明确分隔符拆分。事实支持、立场与首手出处分别做typed判断，绑定实际片段版本。
- **ready同时要求有本关键词合格材料、S>1、没有已知缺失事实。** 缺失的第8个事实不能被其余7个高分掩盖。
- 多片段可经真正的有界联合判断共同提供F，但证据束不获得A/R，不制造虚构独立来源。组成见证必须保留到最终检查。
- 最终覆盖门恢复为>0.85；明确缺口、未知必要判断、未解矛盾、日期/版本不符均否决。没有把实验0.60放行门迁入生产。
- 不提高72逻辑调用/80HTTP/1.2M估算token等硬帽。每轮至多4次联合判断，保留最终检查空间；微批轮转目标，预算不足公开pending。
- 公共输出新增A/F/R及事实状态；共享事实列表只在目标首个关键词记录一次。taskId/canonicalId区分同名目标。分页先为元数据留空间，诊断过大时裁剪预览/重复问题文本，不裁剪真实证据池。

## 验证中出现的失败

- 增加联合判断后，“不完整片段”旧mock默认让所有新问题成功。修正负例fixture，让联合判断明确返回不足；正例另测两个片段确实共同回答。
- 最大合法事实元数据产生62210字符，超过60000诊断上限。增加共享元数据去重及重复问题文本裁剪后通过。
- 一次完整回归因分页超预算警告改写打破旧提示契约。恢复原有关键措辞，并重新跑完整入口通过；没有放宽旧断言。

原临时日志保留在本次执行的 `/tmp/search-boost-fact-*.log`、`/tmp/search-boost-facts-regression-*.log`；不是重新创建实验环境。可在当前仓库用上述命令重跑离线检查。

## 仍然存在的限制

1. 相关性/支持度/出处都是模型特征，不是外部核实的事实或校准概率。模型可以在联合判断与最终判断中犯同一种错误。
2. 近重复识别有候选桶/比较数上限，会漏掉某些改写/翻译；站点分桶不是完整公共后缀解析，可能保守合并不同作者。
3. 未明确拆分的复合问题仍可能需要联合判断；有界片段选择不能保证每次选中所有互补材料。
4. 相反立场可能来自不同条件，最终模型仍需检查作用域。预算不能容纳必要见证时宁可不足，不删除冲突后宣布完成。
5. 多目标/长片段/大量事实明显增加费用与积压，500是全局候选上限，不是每个任务都能审完500条的承诺。
6. 当前未新增网页链接爬取；后续主要按关键词/事实缺口补搜。真实质量改进需要新的独立数据与授权预算验证。
