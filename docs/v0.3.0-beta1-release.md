# v0.3.0-beta1：控制台与五平台社区检索测试版

版本：**0.3.0-beta1**。发布通道为 npm **`beta`**，Git 标签为 **`v0.3.0-beta1`**；不移动 npm `latest`，也不将开发分支合并到稳定分支。标签 / 源码存在不等于 npm 已发布，请以 registry 查询结果为准。

## 安装与通道

```bash
npm install -g search-boost@beta
# 固定此次版本：
npm install -g search-boost@0.3.0-beta1

search-boost                  # 快速配置向导，保留原有入口
search-boost tui              # 独立全屏控制台
search-boost tui --preview    # 离线只读快照，无需 TTY
search-boost tui --dry-run    # 预览配置变更，不写入、不查询额度
```

安装 beta 会替换本机的全局 `search-boost` 命令，但不改变 registry 上的稳定通道。已有宿主请按实际范围刷新接入，再重启 / 重连；运行中的旧适配器不会因 npm 更新而自动变成新代码。

## 本版本内容

- **独立控制台**：固定分类 → 条目 → 详情三栏，表单 / 确认留在详情栏；支持逐级返回、草稿恢复、准确滚动、光标编辑与窗口缩放。Ayu Dark / TokyoNight Dark 主题独立保存，不改变快速向导的布局。共用底层配置与适配器，不新增运行时依赖。详见 [控制台](console-tui.md)。
- **控制台额度**：Tavily 的独立 credits 上限、Brave 长周期请求配额、TinyFish 账户钱包；Exa / AnySearch 明确显示需手动查询的边界。联网前默认取消，Brave 明示一次可能计费的真实搜索。凭据 / 地址隔离内存快照，支持冷却、取消与迟到结果丢弃，不自动刷新。详见 [额度接口](engine-quota.md)。
- **五平台社区检索**：Reddit、X、B站、知乎、小红书，明确来源、平台独立过滤、类型化证据、逐渠道失败状态、内存分页与可选私有保存 / 恢复。fused / Adaptive 共享平台参数与候选核心。原公开 `x_search` 改为 `community_search` 的 `engines:["x"]`；X 凭据命令保留。浏览器桥必须由用户手动启用，不自动登录、导出 cookie 或绕过验证。详见 [社区检索](community-search.md)。
- **判断配置**：保留 Jev / 自部署 Laya 专用适配器、命名配置与 schema v6 历史兼容。快速向导和控制台均支持查看 / 编辑 / 使用 / 删除；编辑不切换 active profile，换址不继承旧 Key。Laya 仍要求完整诊断与固定离线容量证据，不把保存配置当作服务验收。详见 [判断协议与容量](v0.2.5-release.md)。
- **文档更新**：中英文 README 同步测试版安装通道、控制台入口、五平台社区功能与使用边界。

## PR 审查与修正

[PR #34](https://github.com/Mr-remon219/search-boost/pull/34) 合并前进行了交互 / 配置审查，以及额度生命周期的独立只读审查。修复提交 `bd649e3`：

1. HTTP 200 后响应体中途断流原被误报为 `invalid_response`；现在归类为 `network_error`，格式错误与超大 JSON 仍归类为 `invalid_response`，取消 / 超时优先。
2. 不可表示的 `Retry-After` 原被丢弃，使查询恢复到 60 秒冷却；现在在当前进程中禁止提前再次查询，而非缩短服务端要求的等待。

新增回归先复现失败，再验证修复。合并提交为 `7bb34c5`。未发现剩余合并阻断问题，**不等于证明软件没有任何 bug**。

## 验证与未覆盖边界

发布门禁为 `npm run prepublishOnly`：语法、CI 策略、精确依赖锁审计、完整隔离行为回归。完整隔离门禁动态发现全部测试入口，覆盖真实分发包的 global / npx 安装、DSH schema、生成资产、MCP / Pi / DSH 协议、配置写入与历史恢复。CI 在 Ubuntu Node 22.13.0、Windows Node 22、macOS Node 22、Ubuntu Node 24 上分别验证最终提交。

合并前修复后的本地验证：92 个隔离入口通过，额度 15 组、独立控制台 43 组通过，依赖审计 0 vulnerabilities。PR 修复 head 的 [CI](https://github.com/Mr-remon219/search-boost/actions/runs/37789382382) 四组通过。一次本地审计遇 registry TLS 连接失败，重试审计后通过；没有跳过门禁或降低标准。

离线测试不证明真实平台 / 账号的覆盖、付费服务行为、浏览器站点未来 DOM、运行中宿主已加载或判断质量。此次不执行真实付费搜索或模型调用。CI 的 runner / action deprecation 提示不代表测试失败，但后续需要维护。

## English summary

This prerelease uses npm `beta`, not `latest`. Install `search-boost@beta` or pin `0.3.0-beta1`. It includes the independent three-pane console, Ayu / TokyoNight themes, consent-based quota snapshots, five-platform community retrieval and Jev / Laya profiles. The quick configuration wizard remains the no-argument command. PR review fixed body-stream error classification and oversized retry intervals; offline gates and cross-platform CI are release evidence, not proof of zero bugs, live host activation or provider coverage.
