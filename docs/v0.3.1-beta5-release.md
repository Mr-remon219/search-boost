## 这一轮改了什么

全屏 TUI 每次按键都会先发整屏清除（`CSI 2J`），再画新画面。方向键只改高亮时也会清屏。在真实终端上，清除和后续绘制之间可以呈现顶部、左栏和主体变黑，而动作行和页脚仍留在下面。进程不退出，Q 仍可用，确认框没打开，所以不会保存。

现在只有行列变化时才整屏清除一次。普通重绘把光标移回左上角，盖住原来的格子，并擦掉每行行尾和光标以下。从动作 2/8 到 3/8、再回到 2/8，以及相邻动作，都只移动高亮。Enter 才打开确认；默认取消不写配置。尺寸变化后的下一次方向键不再清屏。

这不是桌面终审通过。父机还要用原来的菜单路径再走一遍。云端没有那台 xfce 终端的 `TERM`、字符行列和 Node 版本，不能用这里的测试否定那两张截图。
