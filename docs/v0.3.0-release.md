# SearchBoost 0.3.0 release notes / 发布说明

This document is the release-note text for the reviewed 0.3.0 package. The package and lock root use 0.3.0. Until the maintainer publishes it, use the local tarball. No npm tag, Git tag, GitHub release, or registry availability is asserted by this file.

本文件是 0.3.0 正式版发布说明。package 与 lock 根版本均为 0.3.0。维护者实际发布前请使用本地 tarball；本文件不表示已执行 publish、tag 或 release。

## Changes / 变更

- Add keyed Firecrawl and Keenable API engines. Free-pool use does not silently call keyed API providers. Their initial weights are not measured quality rankings. Provider charges may apply; check with the provider.
  新增需要 Key 的 Firecrawl 与 Keenable API 引擎。free 池不会静默调用 Key 引擎。初始权重不是实测质量排名。可能产生费用，以服务商为准。
- Preserve community content and typed community_data across the MCP output contract. Web and X rows remain compatible.
  MCP 输出契约保留社区正文与 community_data；Web 与 X 结果保持兼容。
- Update dependency compatibility, including Zod 4 schemas, without relaxing the audit gate.
  更新依赖兼容性（含 Zod 4 schema），不放宽 audit 门禁。
- Interactive uninstall now names the selected host integrations it removes and states that it does not uninstall the npm package. Help explains that an explicit --target uninstall runs without confirmation.
  交互卸载明确只移除所选宿主接入、不卸载 npm 包；help 说明显式 --target 卸载不经确认直接执行。
- Keep runtime files, root user documents, SECURITY.md, and an explicit user-doc allowlist in the npm package. Internal review files are excluded.
  npm 包只含运行文件、根用户文档、SECURITY.md 与用户文档白名单，排除内部审阅文件。

## Security fixes / 安全修复

- API keys and endpoint settings are read only from the user's own configuration store or an explicitly selected file. A key file in the current workspace is no longer discovered automatically.
  API Key 与端点配置只从用户自己的配置库或显式指定文件读取，不再自动采用当前工作区内的 key 文件。
- Page fetching applies stricter destination checks to every hop, including more non-public address forms. A selected HTTP(S) page proxy now requires explicit trust, and proxy-to-direct fallback is a separate opt-in.
  页面抓取对每一跳执行更严格的目标检查，覆盖更多非公网地址形式。选中的 HTTP(S) 页面代理需显式信任，代理失败改直连另需单独开启。

## Proxy migration / 代理迁移

`proxy_trust_required` requires `SEARCH_BOOST_TRUSTED_PROXY=1` only when you trust the selected HTTP(S) proxy's remote DNS and destination ACLs. `proxy_fallback_disabled` keeps direct egress off. Repair the proxy first. Separately set `SEARCH_BOOST_PROXY_DIRECT_FALLBACK=1` only if you accept the egress-IP/privacy cost. Both switches also accept `true`. Set accepted values in the MCP server environment and restart the server.

两个开关互不替代。固定用户 API 网关不要求页面代理信任，但代理故障同样默认不直连。不可见系统 TUN 无法可靠检测，不提供物理 public-only 保证。详见[网络策略](network-policy.md)。

## Install / 安装

Before publication, install the reviewed local tarball:

```sh
npm pack
npm install -g ./search-boost-0.3.0.tgz
search-boost --version
```

Only after an actual release can a registry command pinned to search-boost@0.3.0 be relied on. Historical beta release notes are unchanged.

发布前使用本地 tarball。真实付费 API 与已登录社区不在无凭据 fixture 验证范围内。
