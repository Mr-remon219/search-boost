# SearchBoost 0.3.0 release preparation / 发布准备

This is a local release preparation, not a publication announcement. The package and lock root use 0.3.0. No npm tag, Git tag, GitHub release, or registry availability is asserted.

本文件是本地正式版准备说明，不是已发布公告。package 与 lock 根版本均为 0.3.0。尚未执行 publish、tag 或 release，npm 通道未改变。

## Changes / 变更

- Add keyed Firecrawl and Keenable API engines from PR40. Free-pool use does not silently call paid providers. Their initial weights are not measured quality rankings.
- Preserve community content and typed community_data across the MCP output contract. Web and X rows remain compatible.
- Strengthen configuration authority and direct page DNS/redirect checks. Explicit page-proxy trust and proxy-to-direct fallback are separate opt-ins.
- Update dependency compatibility, including Zod4 schemas, without relaxing the audit gate.
- Keep runtime files, root user documents, SECURITY.md, and an explicit user-doc allowlist in the npm package. Internal review files are excluded.

## Proxy migration / 代理迁移

`proxy_trust_required` requires `SEARCH_BOOST_TRUSTED_PROXY=1` only when you trust the selected HTTP(S) proxy's remote DNS and destination ACLs. `proxy_fallback_disabled` keeps direct egress off. Repair the proxy first. Separately set `SEARCH_BOOST_PROXY_DIRECT_FALLBACK=1` only if you accept the egress-IP/privacy cost. Both switches also accept `true`. Set accepted values in the MCP server environment and restart the server.

两个开关互不替代。固定用户 API 网关不要求页面代理信任，但代理故障同样默认不直连。不可见系统 TUN 无法可靠检测，不提供物理 public-only 保证。详见[网络策略](network-policy.md)。
