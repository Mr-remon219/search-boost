# search-boost MCP @ Grok Build

Server id: `search-boost` in `~/.grok/config.toml`.

## Proactive default (bounded)

Use search-boost for **verifiable facts and citations**; native Grok browse for open exploration.

**Doubt → one `fused_search`.** Don't duplicate search-boost and generic browse on the same query.

## Tools

| Tool | Use |
|------|-----|
| `fused_search` | Web facts, docs, benchmarks |
| `fetch_page` | Long-form page text |
| `x_search` | X/Twitter (merged ranking) |
| `deep_research` | Compare / survey |
| `search_stats` | Diagnostics |

## Policy

Rule: `~/.grok/rules/search-boost.md` · resource `search-boost://policy`.

## Keys

Optional — run `search-boost config keys`.
